Posting Assistant

An AI posting agent for your desktop. Pick videos and posts from your computer, let it write captions in your own style, and schedule them to many channels in one go.

Who made it

Posting Assistant is made by Bunnys Framelab (Bunny). Instagram: @bunnysframelab.

It is built with Electron. The AI parts run on a model that you choose, and by default that is a local model on your own PC.

Why it exists

Posting the same video to YouTube, Instagram, TikTok and other channels means uploading it again and again, rewriting the caption for each platform, and picking times by hand. That is slow and easy to get wrong, especially when you run more than one account.

Posting Assistant does that work for you. You say what to post and where, it writes the captions, opens the real scheduling site in a private window, fills everything in and checks the result before it finishes.

Who it is for

Video creators

Short-video and channel owners who post the same content to several platforms.

Social media managers

People who look after several accounts. Each account keeps its own private sign-in.

Small teams and agencies

Anyone who wants a repeatable plan: a folder of videos, a sheet, and a "post the next N" button.

Install

Windows 10 / 11

  1. Download Posting Assistant Setup 1.6.0.exe from the Releases page of this repository.
  2. Run it, choose a folder, and finish. A desktop shortcut is created.
  3. Windows may show a SmartScreen warning because the installer is not code signed. Choose "More info", then "Run anyway".

macOS (Apple Silicon and Intel)

  1. Download the .dmg for your Mac (arm64 for M1 and newer, x64 for Intel) from the Releases page, or build it with the "Build Mac app" workflow under the Actions tab.
  2. Open the .dmg and drag Posting Assistant into Applications.
  3. The app is not signed or notarized. The first time, right-click the app and choose Open, then confirm. If macOS still blocks it, run this once in Terminal: 
    xattr -dr com.apple.quarantine "/Applications/Posting Assistant.app"
Mac status. The Mac build is made by an automated build and has not been tested on a real Mac by the author. Core posting and the writer should work. Automatic install of Ollama and the speech engine is Windows only, so on a Mac you install those two yourself (see below). Please report problems in the Issues tab.

First run (about 10 minutes)

  1. Pick a data folder. Windows uses a folder on a non-system drive when one exists. Mac uses Documents/Posting Assistant Data. You can change it in Settings.
  2. Set up an AI model (page "AI models"). Easiest is Ollama:
    • Windows: the app can download and install Ollama for you.
    • Mac: download Ollama from ollama.com/download, open it once, then press Refresh in the app.
    • Pull or import a model. A vision model helps because it can look at your video frames. Bigger models need more memory, so pick one that fits your computer.
  3. Add an account (page "Accounts"). Press Add, sign in to Buffer once in the window that opens, then let the app read your channels. You need a Buffer account. The free plan keeps 10 queued posts per channel.
  4. Optional, speech to text (Models, Speech to text). Windows: press Install. Mac: run brew install whisper.cpp in Terminal first, then choose a speech model in the app.

How to use it

Post a video from chat

  1. Open Chat and drag in one or more videos.
  2. Type what you want, for example: post this to @MyAccount tomorrow 7:30pm, funny tone.
  3. The agent shows a plan. Check the accounts, channels, captions and times, then confirm.
  4. Watch it work in Monitor. It writes the captions, fills the Buffer composer, sets the date and time, checks the result, and confirms.
Try drafts first. Ask for "save as draft" the first time. Nothing is scheduled until you are happy.

Post a whole folder

Use Workflows: choose a folder and the channels, then press "next N" to schedule the next batch. A CSV sheet keeps track of what is done.

Write without posting

Use Writer for scripts, LinkedIn posts, newsletters and threads. Save the ones you like.

Competitor study

Open Competitor study and paste a profile link.

  • Study profile: captions, hashtags, best days and hours, hooks and tone. Works for YouTube, Instagram, TikTok, Facebook, LinkedIn, X and Threads. The result can become a caption style, a format or a skill.
  • Viral posts: reads views for every post and marks the ones that beat the profile's typical views (default 3 times, adjustable to 2, 5 or 10). Shows Recent viral, All viral and a chart of all posts. Open any post for a breakdown of hook, topic, structure, why it spread and ideas to reuse.
  • Full journey: charts of when the channel started, when views started, when growth started, and which post was the game changer, with phases and quiet periods.
  • One post: paste a single video link for a full breakdown.

Viral posts, journey and one post work for YouTube, TikTok and Instagram only. Facebook and LinkedIn do not show per-post views publicly, so they are not supported there.

Privacy and safety

  • Your data stays on your computer. There is no Posting Assistant server and no tracking.
  • Passwords are never typed by the app. You sign in yourself in each account's private window. Cookies are stored per account.
  • Saved API keys are encrypted with the operating system (Windows DPAPI, macOS Keychain) and never shown in the interface or logs.
  • The app window runs sandboxed with a strict content policy. Model output is shown as escaped text and never executed.
  • Safety checks while posting: only the target channel is switched on, the final button is checked, it stops on login or captcha pages, and a finished post is never sent twice.
  • Skills you import from GitHub or ZIP files are scanned for risky content before use.
  • Downloads happen only when you press Install: the optional Ollama installer, the whisper.cpp release and the speech models come from ollama.com, GitHub and Hugging Face. The Windows installer is unsigned.

Honest limits

  • The app drives websites you do not control. If Buffer changes its page, a step can fail. It then falls back to an AI click agent and tells you.
  • Reading TikTok and Instagram for the viral features follows the page layout but has not been verified live. Login walls can block it. Choose a signed-in account under "View with".
  • YouTube dates on old posts are coarse, so some dates are estimates and are marked with ~.
  • The model cannot watch the video. Breakdowns use titles, descriptions and numbers only.
  • Jobs run one at a time.

Build it yourself

You need Node.js 24 or newer.

npm install
npm start            # run from source
npm run dist         # Windows installer (run on Windows)
npm run dist:mac:arm64   # Mac, Apple Silicon (run on a Mac)
npm run dist:mac:x64     # Mac, Intel (run on a Mac)

No Mac? Open the Actions tab on GitHub and run Build Mac app. It builds both Mac versions and attaches them to the run.
